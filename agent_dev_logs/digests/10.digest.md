## 🎯 Goal
Accept any flexiconv-supported, text-containing format (pdf, docx, odt, rtf, html, md, txt, epub, tei, conllu, …;
PAGE XML and hOCR per the 08-02 task) as raw input, converted **to TEITOK XML**, while CSV/XLSX keep stages 1–4
unchanged. Agreed at the meeting: about inputs, not about post-processing outputs.

## 🧭 Architecture (as built, v0.21.0)
1. **Conversion step** — `api_flexiconv.sh` scans `INPUT_DOCS_DIR` for the exact extensions in
   `FLEXICONV_FORMATS` (incl. `xml hocr`) and calls `api_util/flexiconv_convert.py` per file →
   `TEITOK_FLEXICONV_DIR` (default `$TEITOK_OUTPUT_DIR/flexiconv`), with a paradata record (`--program
   nlp-enrich`, component `flexiconv`). It runs by hand or as the first stage of `run_pipeline.py
   --with-flexiconv`; the REST service does not reach it (see #38 action F for the decided service path).
2. **Adapter** — `flexiconv.api.run_convert(in, out, to_format="teitok", options={"force": …})`, checking
   `ConvertResult.success`; CLI fallback `flexiconv --no-auto-install [--force] -t teitok IN OUT` (timeout 300 s);
   `FlexiconvNotInstalled` / `FlexiconvConversionError` → one line + exit 1. Output `<stem>.teitok.xml`, or
   `<stem>.<ext>.teitok.xml` when the input directory holds convertible same-stem siblings
   (`flexiconv_convert.output_path_for`, `:93-109`); existing output kept unless `FLEXICONV_FORCE=true`.
3. **Optional dependency** — `requirements_flexiconv.txt`:
   `flexiconv[docx,odt,md,pdf,rtf] @ git+https://github.com/ufal/flexiconv.git@v0.3.10`, not in any
   Dockerfile; GPL-3.0-or-later, recorded in `para_config.txt` as a conditional component.
4. **Readers** — `api_util/teitok_read.py` (canonical copy; llm-enrich re-vendors it, pinned by SHA-256): rows
   from `<s>`, else `<lb/>` lines for tokenized documents (PAGE/hOCR/ALTO output), else leaf text blocks
   (`p head item cell l u ab quote`) for untokenized ones (txt/md/docx/pdf/html…). Keywords and the LLM read the
   converted files directly; with `FLEXICONV_ANNOTATE=true` the converted file also feeds stages 1–4 (#38).
5. **Gate** — `api_flexiconv.sh` ends with `validate_teitok_xml.py "$TEITOK_FLEXICONV_DIR" --allow-empty
   --profile core`; `api_4_stats.sh`'s writer gate `--exclude`s that directory.
