## 🎯 The task
A locally hosted LLM gets a line of an OCR'd Czech archaeological report, the controlled vocabulary (AMČR heslář + TEATER), and an output template. It returns the vocabulary terms that describe the line, as schema-valid JSON:
- `extracted_keywords_cs`/`_en`;
- `teater_category` (a misnomer kept for compatibility: both sources);
- `teater_category_ids`;
- `confidence_score`.

The work has two halves:
- **the machine** (backend, constrained decoding, prompt, paradata): built;
- **the vocabulary** (which terms, how grouped, how deduplicated, how scored): ruled and built; only the scoring data is missing.

**The D1 rubric:**
- **D1-a:** decay by rungs (`0.5 ** rungs_above`), with the strict number beside it. A pick narrower than gold scores 0 and has its own cell.
- **D1-b:** either side of a composite pair counts. This is the scoring half of m7 (keep both sides, linked by `same_as`).
- **D1-c:** label only. The ids are provenance.
- **D1-d:** strict match on the annotator's pick from `candidate_terms`. For split homonyms, the qualified form is resolved from `teater_category_ids`.
- **D1-e:** category accuracy per facet and overall; P/R/F1 on `_cs`; `_en` as a consistency check; meta-text in its own cell.
- **D1-f:** a context term where gold is content is an error, with its own confusion-matrix cell.

**Minor rulings:**
- m1: the `kostel` objection was a dedup artefact.
- m2: the `muzeum`, `památková péče`, `zahrada` and `přírodní útvar` moves.
- m3: `Other` is empty; meta-text answers the "nothing fits" case.
- m4: no blanket AMČR-wins rule.
- m5: the May ranking is void as a production signal.
- m6: the prompt/schema contract (meta-text at index 0, temperature 0, most-specific preference, priority order).
- m7: composite labels keep both sides.

**Open, no ruling owed:**
- **A2-grouping:** does the facet layout change results? `PROMPT_VOCAB_GROUPING=facet_sub|facet|flat` makes it a flag flip, but it needs the scorer.
