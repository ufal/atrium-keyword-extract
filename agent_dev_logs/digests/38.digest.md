## 🎯 Goal
Documents converted by flexiconv (`api_flexiconv.sh`) used to end as bare TEITOK: no sentences, lemmas,
POS, entities or ids. With `FLEXICONV_ANNOTATE=true` they go through this repo's own stages 1–4 and come
out as TEITOK format 2 with their layout, and the document record gets entities with boxes and TEITOK
references. The converted file is an intermediate.

## 🧭 Architecture (as released in v0.21.0 — verified 2026-09-24; line numbers at `3654e73`)
1. **Switch** — `config_api.txt:79` `FLEXICONV_ANNOTATE="${FLEXICONV_ANNOTATE:-false}"`;
   `run_pipeline.py --with-flexiconv` (`:668-672`) adds `api_flexiconv.sh` as the first stage
   (`_FLEXICONV_STAGE`, `:68-73`, `:463-465`) and exports the flag to every stage (`:763-765`).
2. **Stage 1** — `api_1_manifest.sh:9-12,76-104` reads `TEITOK_FLEXICONV_DIR/*.teitok.xml` (not recursive).
   `build_manifest_row.py` takes the rows `teitok_read` gives (`_read_teitok`, `:98-106`; document order,
   `:111-116`); `--doc-id-only` prints the id and writes nothing (`:131-153`). A table with the same
   `doc_id` wins (`TABLE_DOC_IDS`, `api_1_manifest.sh:41,52,81-87`, exact string match); an empty
   conversion is skipped with a paradata reason (`:95-102`).
3. **Stages 2–3** — unchanged (UDPipe, NameTag).
4. **Stage 4** — `summarize_nt_udp.layout_source()` (`:495-518`): the document's ALTO, else its converted
   file (`--flexiconv-dir`, passed by `api_4_stats.sh:48-51,103`). One result serves the writer
   (`:593-606`) and the document hook. `api_util/teitok_layout.py` (`parse_teitok_layout`, `:112-251`)
   returns `_parse_alto()`'s five structures (`teitok_alto.py:327-332` dispatches TEI roots to it):
   - pages ← `<pb>` with an image (`facs`) or a size (hOCR `pb@bbox`, `<surface lrx lry>`), `:148-175`;
   - lines ← `<lb bbox>`, `:212-217`;
   - words ← `<tok bbox>`, or the words of leaf blocks without coordinates, `:218-222`, `:236-239`;
   - blocks ← innermost `div p head item cell l u ab quote`, element name (or `div@type`) as `subtype`;
   - meta ← converter + version, original file name (`source_name`, `:62-77`).
5. **Writer** — `teitok_alto.write_teitok_merged` writes format 2 (`WRITER_FORMAT = "teitok-2"`, `:57`,
   stamped at `:957`); the header names flexiconv and the original document (`orgfile` `:934-940`,
   `<change who="flexiconv" type="converted">` `:999-1004`). Strings without coordinates still place a
   token on its page, block and line (`_align_tokens_to_alto`, `:520-531`).
6. **Gate** — stage 4 validates `TEITOK_OUTPUT_DIR` with the writer XSD, excluding the flexiconv
   directory (`api_4_stats.sh:161-174`); `api_flexiconv.sh` gates its own output with `--profile core`.

## 🔍 Round-4 findings (▶ = reproduced in a scratch run; others read from the code)
- ▶ **Chunks are written as pages.** `call_udpipe.merge_conllu_chunks` (`:117-118`) writes
  `# page_break = true` before the first sentence of every UDPipe chunk after the first (chunks are
  ~`WORD_CHUNK_LIMIT=900` words, `chunk.py:53`). `call_nametag.build_sent_page_map` (`:100-140`),
  `summarize_nt_udp._collect_merged_rows` (`:374-450`) and the writer (`teitok_alto.py:1171`) read it
  as a new page. Stage 1 knows each row's `page_num` but joins the text with `\n` and drops it
  (`build_manifest_row.py:125-127`).
  - `data_samples/CTX000000002` has 4 real pages (manifest, `DOC_LINE_CATEG`), yet `NE/` has only
    `CTX000000002-1.tsv` and every `UDP_NE` row says `page_id` 1.
  - With ALTO, a chunk start in mid-page moves a sentence under a phantom `<pb n="P+1">`
    (`b-3.1`, `lb-3.1`); on the one-page CTX000000003 it adds `<pb n="2">` with no surface.
  - Without layout, every chunk becomes a `<pb>`. The issue's "`# page_break = true` has consumers,
    no producer" is therefore wrong, and README "Chunking and page boundaries" (`:361-370`) says the
    marker is written before "every sentence that began a new page", which it is not.
- ▶ **A sentence that crosses a page stays on its first page.** `<pb>` is emitted only between
  sentences, so the page-2 words keep `lb-1.N` ids under `<pb n="1">` with page-2 boxes. It is in the
  released sample: `data_samples/TEITOK/CTX000000002.teitok.xml`, s-5, page 4's first line ("Soubor
  nálezů…", bbox `220 160 1220 200`) is `lb-3.3` under `<pb n="3">`. The XSD does not allow `<pb>` inside
  `<s>` or `<name>`; upstream xmltokenizer treats `pb`/`lb`/`cb` as anchors that may fall inside `<s>`.
- **Converted-document identity (✔ checked).** Stage 1 gives a converted file the id
  `canonical_doc_id(full name)` (`report.txt.teitok.xml` → `report.txt`), stage 4 matches
  `canonical_doc_id(stem)` (`report.txt` → `report`, `summarize_nt_udp.py:514-517`). A table
  `report.csv` plus `report.txt.teitok.xml` are both annotated, and when `report.txt.teitok.xml` and
  `report.md.teitok.xml` both exist the first one sorted silently serves `report`. README `:913`,
  `:929-932` describe the failing pairing as working.
- **Layout fidelity.** `<pb facs>` is always written, with an invented `{doc}-{N}.png` when there is no
  image (`teitok_alto.py:1130-1131,1188-1191`: txt/md conversions, every `/enrich` output).
  `teitok_layout` ignores `pb@n`, `<surface><graphic url>` and flexiconv's zones; PAGE-derived surfaces have
  no size. Upstream conventions not met: split-off punctuation keeps its word's box (flexiconv gives it
  none, `alto.py:210-221`, `hocr.py:153`); the page size is not repeated as `pb@bbox="0 0 W H"`.
- **Gate.** Stage 4 and the service's `_schema_verdict` run the XSD only (profile `xsd`); `lint_core`
  runs only under `--profile core`. Ids are `xs:string`, so duplicate `pb`/`lb`/`n`/`b` ids and dangling
  `sameAs`/`corresp` are never detected.
- **flexiconv failures look like success.** `api_flexiconv.sh:60-63` records a failed conversion as
  `skip`; `run_pipeline._is_empty_failure` (`:364-377`) treats an all-skipped stage as a resume, so a
  `--with-flexiconv` run without flexiconv installed ends green with nothing converted.
- **Service.** `/enrich` accepts `.csv/.xlsx/.txt` only (`service/enrichment.py:184-192`) and derives
  `INPUT_ALTO_DIR=""` (`:259-260`), so its TEITOK never has a layout; an XSD-gate failure comes back as
  502 "empty run, exit 1" (`:513-518`); the response has no TEITOK verdict. `/rescale`
  (`service/rescale.py:28-77`) and `fix_teitok_bboxes.py` give every `<surface>` the first surface's size,
  and `--dx/--dy` shifts are not clamped, so a negative box halts the next stage-4 gate.
- **Upstream bugs (report, do not work around):** flexipipe takes a token's number from the digits of
  its document-global id, so heads go wrong from the second sentence; flexiconv `load_teitok` ignores
  `<dtok>`; flexicorp's `r"\\b…"` phase patterns never match. The README's "no loss through
  flexiconv/flexipipe" is too strong.

## 🛠 Round-4 change set (2026-09-24, implemented; replaces the issue's four checkboxes)
- **A — pages come from the layout (P1, P2).** Stage 1 writes `<doc>.rows.tsv` next to `<doc>.txt`
  (page, line, page label, text of every line; first line `# source = <table>`) —
  `api_util/page_rows.py` (new), `build_manifest_row.get_rows`; stage 2 copies it to `UDP/`
  (`api_2_udp.sh`). `merge_conllu_chunks` writes `# chunk_start = K`; every reader treats it and the
  old `# page_break = true` as a chunk start. Pages are placed by counting UDPipe's own line-end marks
  (`SpacesAfter=\n`, escape-aware, plus chunk starts), verified row by row, else by character
  alignment, else — no rows — only the old `sent_id` restart. Consumers: `call_nametag` (per-token
  pages, `NE/<doc>-P.tsv` = real page P), `summarize_nt_udp._collect_merged_rows` (CSV `page_id`,
  summary pages, an entity on its `B-` token's page), the writer and the document hook
  (`parse_and_align_conllu(rows=…)`: layout string page, else row page, else the previous page;
  aligned pages out of reading order are dropped as outliers — longest non-decreasing run). The writer
  emits `<pb/>` where the page changes, inside `<s>`/`<name>` when needed, pages only forward, every
  layout page with its `<pb>`. XSD: `pb` allowed in `s` and `name`, `pb@facs` optional, `pb@bbox` added;
  the stamp stays `teitok-2`. Migration: `page_rows.py resplit` re-partitions existing NE files.
  Evidence: the released sample now has `<pb n="4" id="pb-4" …/><lb id="lb-4.1" bbox="220 160 1220 200"/>`
  inside s-5 before "Soubor", no `lb-3.3`; a real `api_4_stats.sh` run gives `page_id` 1–4
  (`tests/test_stats_stage_pages.py`); `tests/test_page_rows.py` (9), `tests/test_teitok_pages.py` (13,
  incl. a three-page two-chunk fixture `tests/fixtures/pages/multichunk.*` and flexiconv v0.3.10 reading
  a `<pb/>` inside `<s>` back); `teitok_read` (vendored to llm-enrich) numbers lines per page, adds
  `page_idx`/`page_label` and splits a sentence at an inner `<pb/>`.
- **B — one identity rule (P3).** `api_util/doc_identity.py` (new): a converted file keeps file identity
  (`report.txt.teitok.xml` = `report.txt`); `find_converted` = exact `{id}.teitok.xml`, else the single
  file whose `canonical_doc_id` matches, else none with an "ambiguous converted layout" warning; stage 1
  skips a converted file exactly when a table claims it (`--table-ids`), stage 4's `layout_source`
  uses the same function. `tests/test_doc_identity.py` (6).
- **C — layout fidelity (P4, P5, U1, U2).** `pb@facs`/`@corresp`/`@bbox="0 0 W H"` only for pages with a
  `<surface>` (no invented images); `pb@n` is the page label (from the converted file's `pb@n` or the
  table's `page_label`); `teitok_layout` takes a page's surface by `pb@corresp` or position, its image
  from `pb@facs`/`surface@facs`/`<graphic url>`, its size from `pb@bbox`/`lrx lry`/`graphic@width
  height`; split-off punctuation sharing an OCR string has no box (as flexiconv); a table-only document's
  `orgfile` is its table; below 90 % aligned tokens the writer warns. flexiconv zones are not carried
  (format 2 has none) — documented.
- **D — gate (P6).** `validate_teitok_xml.py` default profile `contract`: the XSD for every file, plus
  `lint_core` (ids unique over all elements, `sameAs`/`corresp`/`head` resolve) and the new
  `lint_writer` (pb-K increasing, `lb-P.L`/`b-P.K`/`fig-P.K` on page P, every `<surface>` with its `<pb>`)
  for files stamped `teitok-2`; older files keep the XSD alone. `api_4_stats.sh` exits **5**
  ("TEITOK output contract failed"). `tests/test_validate_teitok.py` (57).
- **E — flexiconv failures (P7).** `flexiconv_convert.py` exits 3 without flexiconv and 1 on a failed
  conversion (`--check`); `api_flexiconv.sh` stops with 3 at once when flexiconv is missing and exits 1
  after converting the rest; `--start-from` any stage skips the conversion. Also P10
  (`BBOX_ORIGIN="${BBOX_ORIGIN:-page}"`) and P11 (the LLM line filter: a missing quality score is
  *unknown*, not 0.0 → Trash; the GPU path passes it as the 7th argument).
- **F — service parity (P8; decided 2026-09-24).** `/enrich` and `/jobs` accept a converted
  `*.teitok.xml` (pre-checked with `lint_core`, 422 with diagnostics) as text + layout, or a
  `.csv`/`.xlsx` with an `alto` part; no GPL code in the image. The workspace gets `layout/flexiconv` or
  `layout/alto`; `.txt` form feeds start pages; exit 5 is its own 500; the envelope reports
  `layout_source` and `teitok_schema_valid`/`_errors`. `/rescale` (new `scale` form) and
  `fix_teitok_bboxes.py` work page by page (`api_util/page_boxes.py`, new), clamp to the page and add a
  `<change type="rescaled">`. `tests/test_service_layout_inputs.py` (6: real stage-1 and stage-4 scripts in
  the service workspace), `tests/test_rescale.py` (26), `tests/test_fix_teitok_bboxes.py` (10).
