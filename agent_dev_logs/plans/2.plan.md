Each writes `data_samples/KW_PER_DOC_LLM_R3_<model>/` with its paradata; a follow-up task runs `score_categories.py` over the five and their committed runs.

2. **(a)** Commit each run with its paradata file. Check `config.prompt`: `category_case_folding` true, `blocks` with the three 10-16 blocks, `composite_halves` 79, the same sha across runs unless a variant is intended.
   - Where the run directories may live depends on step 4.
3. **(a)** Read `score_categories.py`'s `before_after.csv`: forced capital labels and the 10-16 watch list (`zvonice`, `prahory`, `Pentelikon`, `jámová kultura`) should drop to 0; `confidence_top2_share` should fall below the 0.94–0.99 of the shortlist. Then the #2 comment: the table, the default model, and whether Option 3 (free decoding, then resolution) is still needed. Option 3 reverses the 3 September "no free-form categories" and needs @motyc and @david-spacil.
   - **Done 10-19 (four of five):** the table is in the digest. Steps 2 and 3 hold for the four complete runs (paradata checked). `qwen3-14b`'s row follows when its run ends; its numbers do not change the choice.
4. **(a) `v1.4.0-beta`** (published 10-19 with `MODEL_KEY` = `qwen-3.8-27b-it`) after the comment: `para_config.txt`, `CITATION.cff`, the spec (two `/info` fields, additive), the CONTRIBUTING row below, and notes saying the vocabulary asset changes (`**suborál`), so the translator rebuilds its list at its next release.

   > **v1.4.0-beta** — The controlled kind is told to copy its category from the list, to pick the most specific term the line supports, and how to score confidence (three prompt blocks with flags, on by default). A category given as one half of a composite term is recorded as the term (`composite_halves.csv`, reviewed per row; `ACCEPT_COMPOSITE_HALVES`). `/info` names the prompt blocks in force and counts the halves. `score_categories.py` reports a run's missing lines, forced labels, confidence spread and agreement, and a re-run against its earlier run (#2). Markdown at the edge of a TEATER label is dropped (`**suborál`): the vocabulary asset changes. Known limits in `service/README.md`.
