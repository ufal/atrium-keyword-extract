## Context
Round 3 made converted documents first-class: with `FLEXICONV_ANNOTATE=true` the flexiconv file supplies
the text (stage 1) and the layout (stage 4), UDPipe/NameTag run unchanged, and the writer emits TEITOK
format 2. The issue listed four follow-ups. Checking them against the code showed that the third one —
"page breaks for table inputs without layout (`# page_break = true` has consumers, no producer)" — is a
symptom of a wider defect: the marker *is* produced, at every UDPipe chunk start, and every stage reads it
as a page. Together with sentences that cross a page (their second half stays on the first page, visible
in the released `CTX000000002` sample), page attribution is wrong for NE files, the per-document CSV, the
document record and the TEITOK facsimile. The rest of the round-4 audit adds an identity mismatch between
stages 1 and 4, a gate that sees only the XSD, silent flexiconv failures, and a service that can never
produce layout.

## Decisions (user, 2026-09-24)
1. **Pages: layout-first.** Pages come from the layout source — ALTO, the converted flexiconv file, or the
   table's `page_num`/`line_num` as a coordinate-free layout. `<pb/>` may sit inside `<s>` (and `<name>`),
   UDPipe chunk starts stop being page breaks, and NE page numbers follow the real pages.
2. **Service parity:** `/enrich` also accepts a flexiconv-produced `*.teitok.xml` and, for tables, an
   optional ALTO file as the layout source. The service image stays free of GPL flexiconv; conversion
   stays in the CLI (`api_flexiconv.sh`).
3. **Dev logs first**; the closed #9/#28 pairs are removed and their leftovers carried here.
4. **The format stamp stays `teitok-2`.** The XSD change is additive (`pb` allowed in more places), no id
   scheme changes, and the hub E2E is strict only for that exact value (`tools/e2e/e2e_assert.py:244`).

### As implemented — where it differs from the actions below
- **A:** without a rows file the writer, NameTag and the summary all keep the old `sent_id`-restart
  convention (an old per-page CoNLL-U), never chunk markers. Aligned pages that go backwards are
  treated as outliers (the longest non-decreasing run of aligned pages is kept; the others lose their
  box) — not planned, needed so one misaligned token cannot drag the rest forward. When an entity's
  first token opens a line or page, its `<lb/>`/`<pb/>` goes before `<name>` (it used to sit inside).
- **B:** `source_doc_id` is `canonical_doc_id` of the file-identity id (name-based), not of the original
  file named in the header — the same answer for every file flexiconv names, and no header parse.
- **C:** the coverage threshold is the writer constant `MIN_ALIGNMENT = 0.9`, a warning; no env knob,
  paradata field or `flexiconv_report.py` column yet.
- **D:** `lint_core` + `lint_writer` apply to files stamped `teitok-2`; format-1 files on disk keep the XSD
  alone, so a resumed run with old files still passes.
- **E:** a failed conversion is still written to paradata as a `skip` with its reason (the hub-canonical
  paradata has no failure record); the stage's exit code 1 carries the failure.
- **F:** the uploaded layout goes to `<workspace>/layout/{flexiconv,alto}/`, outside `in/`, which stage 1
  reads as tables; the `alto` part is accepted with `.csv`/`.xlsx` only.
- **Cross-repo:** atrium-llm-enrich re-vendored `teitok_read.py`/`flexiconv_convert.py`, fixed its line
  filter and GPU path, and rebuilt `xml_to_md`'s TEITOK layout reader on the same page model;
  alto-postprocess's `read_tei` keeps `pb@n` and blank pages and reads tokenized TEITOK by `<lb/>`; the
  hub's `assert_teitok` checks element kinds and entity pages.

## Strategic actions
Each change set lands with its tests and docs; the order below is the implementation order.

### E — flexiconv failure signalling and small fixes (CS-E)
1. `api_util/flexiconv_convert.py` exits 3 on `FlexiconvNotInstalled`; `api_flexiconv.sh` stops with a
   clear message when flexiconv is missing; a failed conversion is recorded as a failure, not `skip`, so
   `run_pipeline._is_empty_failure` (`:364-377`) no longer reads it as a resume; the flexiconv stage
   honours `--start-from`/`--skip-*`. `flexiconv_convert.py` is vendored → llm-enrich re-vendors it.
2. `config_api.txt`: `BBOX_ORIGIN="${BBOX_ORIGIN:-page}"` (it is the one TEITOK knob still assigned bare).
3. `llm_utils.py` (this repo's copy): the GPU path passes the 7th argument to `_should_process_line`
   (`:1691`, `:1933`); rows without a quality score carry `None` = "unknown, process it" (today a
   `.teitok.xml` input is forced to Trash). Same fix in llm-enrich.

### B — converted-document identity (CS-B)
4. New `api_util/doc_identity.py`:
   - `converted_doc_id(path)` — the file name minus `.teitok.xml` (file identity, as stage 1 does today, so
     nothing is renamed);
   - `source_doc_id(path)` — `canonical_doc_id` of the original file named in the header, used only when
     flexiconv's naming rule (`flexiconv_convert.py:95-111`) reproduces the file name;
   - `find_converted(doc_id, dir)` — exact `{doc_id}.teitok.xml`, else the single file whose
     `source_doc_id` matches, else `None` with an "ambiguous" warning (replaces the silent first-sorted
     pick at `summarize_nt_udp.py:514-517`);
   - `layout_source(doc, alto_dir, flexiconv_dir)` moves here (re-exported by `summarize_nt_udp`).
5. **Claim rule** at stage 1: a converted file is skipped exactly when a table id T has
   `find_converted(T) == F` — `build_manifest_row.py F --doc-id-only --table-ids FILE --flexiconv-dir DIR`
   prints `doc_id<TAB>claimed_by`; without the new flags the output is unchanged. `canonical_doc_id`
   (hub-canonical, byte-identical in five repos) is not touched.

### A — page provenance, layout-first (CS-A1, CS-A2)
6. **Stage 1** normalises row text (every `str.splitlines()` separator and CSV-embedded newline becomes a
   space, so one row = one line of `<doc>.txt` = one UDPipe line end) and writes `<doc>.rows.tsv`
   (`page` ordinal, `line`, `label` = `page_label`/`pb@n`, `text`) next to `<doc>.txt`.
7. **Stage 2** copies it to `UDP/<doc>.rows.tsv` with the CoNLL-U it annotated. TEMP is container-local
   (only `./data` is mounted) and a resumed run skips stage 2 (`api_2_udp.sh:27`), so the pair must be
   frozen together; readers prefer the UDP copy and use the TEMP copy only if it verifies.
8. New `api_util/page_rows.py` (stdlib; not vendored):
   - primary placement counts UDPipe's `SpacesAfter=\n` line ends (escape-aware) plus chunk starts —
     on all three samples the marks equal the non-empty rows minus one — and verifies the row count and
     the whitespace-free text of every row;
   - fallback: a character cursor that reuses `_align_tokens_to_alto` over coordinate-free strings;
   - last resort: legacy `sent_id == 1` resets (real pages in old per-page files) with a warning;
   - `word_pages`, `page_labels`, and a `resplit` CLI that re-partitions existing NE TSVs by page without
     calling NameTag.
9. `merge_conllu_chunks` writes `# chunk_start = K`; every reader treats it — and the old
   `# page_break = true` — as a chunk start, never a page.
10. `call_nametag` assigns each token its page from the rows (`NE/<doc>/<doc>-P.tsv` = real page; a
    sentence crossing a page splits across two files; order stays increasing, so
    `get_sorted_tsv_content` is unchanged). `_collect_merged_rows` takes pages from the stage-4 resolver
    and counts an entity on its `B-` token's page.
11. **Writer** (`teitok_alto.py:1145-1222`):
    - unit page = layout box `page_idx`, else the row's page, else the previous unit's page; a table-only
      document gets a coordinate-free *rows layout* (`layout_source`: ALTO → converted TEITOK → rows);
    - the sentence-level trigger (`sent id == "1"` / marker, `:1171`) goes; `open_page(p)` writes
      `<pb n="{label or p}" id="pb-{p}">`; pages only move forward (no duplicate ids), and pages skipped
      in between are opened so every `<surface>` keeps its `<pb>`;
    - mid-sentence, the `<pb/>` goes before the token's `<lb/>` — before `<name>` when the token opens it,
      inside it otherwise — and `_tok_xml` renders in the same pass that switches the page scale;
      `lb-P.L` counts per new page; figures of a page opened mid-sentence wait for the next body-level
      position (never inside `<s>`); a `<div>` stays on the page it opens on (documented limitation);
    - `document_hook` falls back to the row page instead of `"1"`.
12. `schemas/teitok/teitok.xsd`: `pb` allowed inside `s` and `name`; `pb@facs` optional.
13. Canonical `api_util/teitok_read.py`: `<s>`-mode `line_num` resets at each `<pb>`; rows gain the additive
    keys `page_idx` and `page_label`; a sentence containing a `<pb/>` yields one row per page part.
    Re-vendored into llm-enrich (hash pins updated).
14. Regression target: released `CTX000000002` s-5 → `<pb n="4" id="pb-4" …/>` before
    `<lb id="lb-4.1" bbox="220 160 1220 200"/>` "Soubor", no `lb-3.3`.

### C — layout fidelity (with CS-A2)
15. `<pb facs>`/`corresp` only when the page has an image or a `<surface>`; `pb@bbox="0 0 W H"` when the
    page size is known (flexiconv's hOCR/xpdf convention).
16. `teitok_layout.start_page`: surface by `pb@corresp` or position; image from `pb@facs`, `surface@facs`
    or `graphic@url`; size from `pb@bbox`, `lrx/lry` or `graphic@width/height`; `pb@n` kept as the label.
    flexiconv's zones are not carried (format 2 has none) — documented.
17. Split-off punctuation that shares an ALTO string with a word gets no box (flexiconv `alto.py:210-221`);
    the word keeps the string box, so entity unions do not change.
18. Text-only files name the source table as `orgfile` (from the rows file), not the intermediate
    CoNLL-U (`teitok_alto.py:940`).
19. Alignment coverage: the writer's `matched X/Y tokens` becomes a paradata field and a warning below
    `TEITOK_MIN_ALIGNMENT` (default 0.9) — the case where the text comes from alto-postprocess
    `--method text-lines` and the layout from flexiconv; `flexiconv_report.py` shows it.

### D — gate (CS-C)
20. `validate_teitok_xml.py`: `lint_core` checks unique `@id` over all elements and resolvable `#refs` in
    `sameAs`/`corresp` (0 duplicates and 0 dangling references in every committed fixture and sample);
    new `lint_writer` for files stamped `atrium-nlp-enrich teitok-2` (increasing `pb-K`,
    `lb-P.L`/`b-P.K`/`fig-P.K` on the current page, `pb@corresp` → a `<surface>`); new default profile
    `contract` = XSD + `lint_core` + `lint_writer`, while `--profile xsd` keeps meaning XSD only.
21. `api_4_stats.sh` exits **5** on a contract failure (1–4 are taken) with the reason "TEITOK output
    contract failed"; `service/api.py` `_schema_verdict` uses the same profile.

### F — service parity (CS-D)
22. `/enrich` and `/jobs`: `file` also accepts `*.teitok.xml` (and `.xml` starting with `<TEI`), pre-checked
    for well-formedness and `lint_core` (422 with diagnostics), word limit from `read_teitok_rows`; an
    optional `alto` part, only with `.csv/.xlsx` (422 otherwise; PAGE/hOCR get the hint "convert with
    `api_flexiconv.sh`").
23. `service/enrichment.py`: uploads go to `ws/in/flexiconv/<doc_id>.teitok.xml` and
    `ws/in/alto/<doc_id>.alto.xml`; `_derive_config` overrides `TEITOK_FLEXICONV_DIR`, `FLEXICONV_ANNOTATE`
    and `INPUT_ALTO_DIR` (added to `_RELOCATED_KEYS`); rows still go through the canonical CSV and the
    claim rule attaches the layout; `.txt` treats a form feed as a page break. flexiconv is never imported.
24. Exit 5 gets its own error ("TEITOK output failed its output contract"); the response gains
    `teitok_schema_valid`, `teitok_schema_errors` and `layout_source` (`alto|teitok|rows|none`).
25. `/rescale` and `fix_teitok_bboxes.py` become page-aware (each surface's own size; a `scale=<factor>`
    form for multi-page files), clamp to `[0, extent]`, and append `<change type="rescaled">`; the clamps
    live in the callers so vendored `bbox_scale.py` keeps its hash. Frontends accept `.xml` and an
    optional ALTO file; `service/README.md` follows.
