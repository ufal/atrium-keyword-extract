## Context
The 30 September meeting put both keyword kinds into one repository and one service:
- statistical: KeyBERT by default, YAKE, legacy KER;
- controlled: an LLM over the AMČR + TEATER vocabularies.

That makes one LLM engine and one vocabulary artefact the property of this repository (atrium-project#72).

The repository was seeded from nlp-enrich's history, so its LLM copy is nlp-enrich's. llm-enrich's copy went to digital-convert and was deleted there in `20dabd8`. It is recoverable at digital-convert `v1.0.0-beta` (`31534d5`).
