## 🏷️ `archaeo` tagset (flat, IOB2)
`O`, `B/I-ARTEFACT`, `B/I-PERIOD`, `B/I-LOCATION`, `B/I-CONTEXT`, `B/I-MATERIAL`, `B/I-SPECIES`.
Separate tagset — **not** remapped into CNEC two-letter codes (they collide / don't exist).
Nested overlaps live in the **data** (`bronze → B-MATERIAL|B-ARTEFACT`); the flat v1 head takes
the first/most-specific tag. Coarse TEITOK `@type` interop: `LOCATION → LOC`, rest → `MISC`.

## Training roadmap (ordered)

### Phase 0 — Learn the loop at ~zero annotation cost (DO THIS FIRST)
1. Run the **full NameTag 3 train/eval cycle end-to-end on Brandsen (Dutch) public data** —
   the point is to exercise tokenizer → training → dev-checkpoint → eval before spending any
   Czech annotation effort. Reuse the ArchaeoBERT annotation **guidelines** (not weights;
   casing matters: `Early Bronze Age` vs `early artifacts`).
2. Confirm the multitagset plumbing: one XLM-R network serving CNEC 2.0 **and** `archaeo`.

### Phase 1 — Build Czech `archaeo` training data
3. **LLM-assisted pre-annotation** (the drafted prompt) over Czech archaeological text → IOB2,
   then human correction (validated/corrected with Opus 4.8, per the issue's framing).
4. Record nested overlaps as pipe-tags in the data now (cheap insurance for a future v2),
   even though flat v1 only consumes the first tag.

### Phase 2 — Train the multitagset model
5. Fine-tune from `nametag3-multilingual-260521` with the locked hyperparameters
   (20 epochs, native optimal-checkpoint on dev validation loss).
6. Evaluate per-type F1 on a held-out Czech set; compare against the Phase 0 Dutch baseline
   loop to sanity-check the pipeline, not the scores.

### Phase 3 — Serve + provenance
7. Deploy either via the **native Python client** (synchronous, alongside FastText/ALTO) or the
   **NameTag 3 Server** REST service (isolates Transformer load, avoids GPU contention with the
   #6 LLM stage) — choose Server if NER and the LLM enrichment must run concurrently.
8. Log extractions through the shared **`atrium_paradata.py`** (tool version, run_id, config) so
   NER provenance matches the rest of the pipeline.

### Deferred — nested-span v2
9. Only after flat v1 is validated: a seq2seq/nested head consuming the pipe-tagged overlaps.
   Keep it parked until v1 earns it.
