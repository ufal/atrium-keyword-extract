# License rationale (see ATRIUM issue #6 licensing breakdown):
#   * No component is "always": which licences apply depends on the method a run uses,
#     and the license of a run is the most restrictive of the components it logged.
#   * KER (the legacy lemma-frequency method of nlp-enrich) is stdlib-only; it adds no
#     third-party license, so the repo MIT base applies for KER-only runs.
#   * KeyBERT is MIT and pulls in sentence-transformers (Apache-2.0); the default embedding
#     model (paraphrase-multilingual-MiniLM-L12-v2) is Apache-2.0.
#   * YAKE is AGPL-3.0 (LIAAD/yake PyPI package). It is selectable in the production image
#     (`method=yake`), and a run that uses it is declared AGPL-3.0 -- the same class of
#     finding as PyMuPDF's in page-classification (atrium-project#72).
#   * The AMCR `heslo` vocabularies (https://api.aiscr.cz/2.2/oai) and the TEATER
#     thesaurus are CC0, as stated by their rights holder (AMCR, atrium-project#6,
#     comment 5867861653, 2026-09-28). They were labelled CC BY-NC 4.0 before, after
#     the OAI-PMH Identify response for the whole repository; paradata written before
#     that date says so. Conditional, because only the vocabulary build and the controlled
#     kind touch them. Names and licences match atrium-translator's para_config.txt.
