## Q1 — geographic, ethnic and dynastic terms (982 terms)

| Rule           | Terms | Branch / list                            | Examples                                               |
|----------------|------:|------------------------------------------|--------------------------------------------------------|
| `teater:2560`  |   391 | 10.2) etnika / ethnic groups             | Keltové, Slované, Germáni, Avaři, Baskové, Anglosasové |
| `teater:2900`  |   317 | 10.3) historické oblasti a státní útvary | Achaia, Afrika, Alpy, Anglie, Andalusie, Aquitaine     |
| `heslar:zeme`  |   250 | AMCR country list                        | Afghánistán, Albánie, Angola, …                        |
| `teater:3076`  |    15 | 10.4) panovnické dynastie                | Habsburkové, Lucemburkové, Přemyslovci, Jagellonci     |
| `heslar:jazyk` |     9 | AMCR language list                       | čeština, němčina, latina, …                            |

**Why this one is not a free choice.** The system prompt currently contains an absolute rule:

> "NEVER select a country name, language name, or geographic region name as the `teater_category` for any line — including 
> administrative lines."

That wording exists because of a real, repeatedly-observed failure: models handed an uncategorisable line ("Obsah", 
"Literatura") reached for a country name out of the residue bucket — `Dánsko`, `Džibutsko`, `Finsko`, `Zimbabwe`. The
guardrail and these exclusions were built together and currently agree with each other.

So there are only two coherent outcomes, not three:

1. **Keep them excluded** (status quo). The guardrail wording stays as it is. Nothing to do.
2. **Reinstate them *and* relax the guardrail in the same change** — replace the absolute prohibition with a preference 
along the lines of *"select a geographic, ethnic or dynastic term only when the line is genuinely about it; prefer an 
archaeological content term otherwise."* Then let the evaluation (workstream D) measure whether it holds.

**The one thing to avoid** is reinstating them while leaving the guardrail absolute. The prompt would then forbid 
exactly what the vocabulary offers, and any score measured afterwards would be measuring that contradiction rather 
than the model. This was flagged in the plan as the option not to take.

A note on `jazyk` (9 language names): it is grouped here rather than with the settled technical lists purely because 
the guardrail's own wording names "language name" explicitly. If you consider languages plainly administrative, 
moving it to "settled" is a one-word change and does not affect the rest of Q1.

| Rule          | Terms | Branch                               | Examples                                                       |
|---------------|------:|--------------------------------------|----------------------------------------------------------------|
| `teater:288`  |   966 | 4) Hraniční obory a přidružené obory | Agnus Dei, Bar micva, Barbizonská škola, Bůh                   |
| `teater:3094` |   471 | 11) Povolání a pracovní činnosti     | abatyše, arcibiskup, armáda, augustiniáni                      |
| `teater:3549` |   148 | 12) Společnost                       | absolutismus, absolutní monarchie, aristokracie, arabské písmo |
| `teater:1`    |   100 | 1) Teorie a přístupy                 | abraze, analýza, archeogenetika, archeolog                     |
| `teater:3091` |    11 | 10.5) války / wars                   | galské války (58–51 př. Kr.), makedonské války                 |
| `teater:2558` |     7 | 10.1) bitvy / battles                | bitva u Gaugamél (331 př. Kr.)                                 |

**No guardrail implication at all.** A profession, a school of thought, or the name of a battle is not a country, 
a language, or a geographic region. Nothing in the prompt forbids selecting one. This question can be answered
entirely on its own merits, and answering it does not require touching the prompt.

**One thing worth saying plainly, because it cuts against the current state.** Under M3 the agreed default is *keep*, 
and exclusion requires "evidence from the enrichment results — for example, if they prove irrelevant for the intended 
content description or introduce systematic and otherwise unsolvable bias/noise." These six branches were excluded on 
an *a priori* reading ("959 concepts of neighbouring disciplines — almost none of it is report vocabulary"), not on 
evidence from results. That is a reasonable-sounding judgement and it may well be correct — but M3 puts the burden 
the other way, and no run has ever been scored with these terms present. If the honest answer is "we don't know yet," 
then under M3 the default reading is that they should be in until a scored run says otherwise.

Battles and wars are the one sub-case where the a priori argument looks strongest to us: those 18 terms are individual
historical events with dates baked into the label (`bitva u Gaugamél (331 př. Kr. : Tel Gomél, Irák)`), which is not 
the shape of anything an excavation report line is "about". But that is an observation, not a recommendation.

## What it costs — the answer is "not much"

The context budget is not a constraint at these sizes. Current prompt vocabulary block, measured on the real artifact:

| Scenario | Terms | Est. vocabulary tokens |
|----------|------:|-----------------------:|
| Today    | 2 074 |                ~16 500 |
| + Q1     | 3 056 |                ~24 300 |
| + Q2     | 3 777 |                ~30 100 |
| + both   | 4 759 |                ~37 900 |

(Estimated at 4 chars/token on the rendered `- cs (en)` lines; Czech diacritics tokenise a little richer, so treat 
these as floors. Even the "both" figure sits well inside the ≥128k windows every candidate model has, and comfortably
under the ~57.9k system-prompt figure already accepted as workable under M6.)

**Applying either answer is a one-line change.** Every branch above is a single entry in `taxonomy_config.json`:

```jsonc
"teater_branch_map": {
  "2560": "__exclude__",     // change "__exclude__" to a facet name to reinstate
  "3094": "__exclude__",
  ...
}
```

Then `python3 vocab_build.py --from-flat` rebuilds the vocabulary, and the CI drift gate confirms the artifacts match. 
Reinstating a branch takes minutes, and is equally cheap to reverse — so this decision does not need to be permanent, only made.
